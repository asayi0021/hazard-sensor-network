Module adc_sensors 

Source
Expand description

Driver for the wind speed and soil moisture sensors.

Provides all the necessary functions for collecting wind speed and soil moisture data. The wind speed sensor (EF04083) operates by reading out a voltage from 0V to 2V which corresponds with wind speeds from 0 to 200 km/h. The soil moisture sensor (SEN0193) operates by reading out a voltage from 0V to 3V which corresponds with soil moisture from 0% to 100%, where 100% represents full submersion of the sensor in water.

Values are collected using the ADS1115 ADC to I2C bus.
