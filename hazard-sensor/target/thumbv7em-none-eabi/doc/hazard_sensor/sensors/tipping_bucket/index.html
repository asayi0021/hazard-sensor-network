Module tipping_bucket 

Source
Expand description

Driver for the DFRobot SEN0575 Gravity Tipping Bucket Rainfall Sensor (I2C mode).

The sensor has no internal electronics of its own for measurement – a magnetic reed switch closes every time the tipping bucket flips, and an onboard companion MCU on the sensor’s PCB debounces/counts these tips and exposes the result over I2C as a set of input registers. Cumulative rainfall is reported by the sensor itself as a raw count multiplied internally by a per-tip rainfall depth (BaseRainfall, in mm), so no conversion math is needed on the host side – only a fixed-point scale-down of the register value.
